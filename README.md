# Legacy Hands of Hope 🌍

**Legacy Hands of Hope (LHOH)** is a modern, responsive React-based website for a non-profit organization dedicated to empowering communities through education, health, and community support initiatives. The website provides information about the organization, its team, events, donation opportunities, and impact.

## 📁 Project Structure
├── public/
│ └── index.html
├── src/
│ ├── assets/ # Images, logos, icons
│ ├── components/ # Reusable React components (Header, Footer, Hero, etc.)
│ ├── pages/ # Main pages (Home, Give, Team, Donate, etc.)
│ ├── App.js # Main React app
│ ├── index.js # Entry point
│ └── styles/ # Optional CSS files
├── package.json
└── README.md


## 🛠️ Technologies Used

- **Frontend:** React.js, HTML5, CSS3, JavaScript (ES6+)
- **Routing:** React Router DOM
- **State Management:** React useState / Context API (if used)
- **Styling:** CSS, responsive grid/flexbox
- **Icons / Assets:** Local assets folder
- **Version Control:** Git & GitHub
